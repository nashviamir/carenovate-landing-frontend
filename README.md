Marketing landing page for **CareHub™ by CareNovate Inc.** — a B2B SaaS platform for smart medication dispensing and digitized task management in Assisted Living and RCFE facilities.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS 3
- Lucide React
- Poppins via next/font
